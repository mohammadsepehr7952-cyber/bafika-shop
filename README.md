# bafika — فروشگاه دستبافت (کاتالوگ آنلاین)

## ساختار فایل‌ها
```
kamva/
├── index.html       صفحه اصلی
├── products.html    لیست محصولات + فیلتر دسته
├── about.html       درباره ما
├── contact.html     تماس با ما (فرم با اعتبارسنجی)
├── cart.html        سبد خرید
├── checkout.html     فرم اطلاعات گیرنده + ثبت سفارش در اینستاگرام
├── reviews.html      نظرات مشتریان
├── css/style.css
├── js/main.js        همه منطق: محصولات، سبد خرید، فرم‌ها، نظرات
└── img/
    ├── logo.jpg       لوگوی برند
    └── products/      عکس‌های محصولات (اضافه کن هرچی خواستی)
```

## اضافه کردن عکس واقعی محصولات
1. عکس‌ها رو بریز داخل پوشه‌ی `img/products/` (اسم فایل انگلیسی و بدون فاصله بهتره، مثلاً `runner1-1.jpg`)
2. توی `js/main.js`، محصول موردنظر رو توی آرایه‌ی `PRODUCTS` پیدا کن و جلوی `images:` مسیر عکس(ها) رو بنویس:

```js
{ id: 1, name: "رومیزی بافت دایره‌ای گلدار", ..., images: ["img/products/runner1-1.jpg"] }
```

اگه محصول چند مدل/عکس داره (مثلاً از چند زاویه یا چند رنگ)، همه رو تو همون آرایه بذار:

```js
images: ["img/products/runner1-1.jpg", "img/products/runner1-2.jpg", "img/products/runner1-3.jpg"]
```

وقتی بیشتر از یک عکس بذاری، **خودکار روی کارت محصول اسلایدر (فلش + نقطه) نشون داده می‌شه** — نیازی به کار اضافه نیست.
اگه `images: []` (خالی) بمونه، همون آیکون کلاف نخ به‌جاش نمایش داده می‌شه؛ یعنی می‌تونی محصول‌به‌محصول، هر وقت عکسش آماده شد، اضافه‌ش کنی.

## نظرات مشتریان
صفحه `reviews.html` یه فرم ثبت نظر داره. چون سایت بک‌اند/دیتابیس نداره،
نظرهای جدید فقط توی **همون مرورگری که ثبت شدن** ذخیره می‌شن (با `localStorage`) —
یعنی اگه یه مشتری با گوشی خودش نظر بده، بقیه بازدیدکننده‌ها اون نظر رو نمی‌بینن،
فقط چند نظر نمونه (`SEED_REVIEWS` توی `js/main.js`) برای همه ثابته.

برای نظرات واقعی و مشترک بین همه، بعداً نیاز به یکی از این‌ها داری:
- یه بک‌اند ساده + دیتابیس
- یا یه سرویس آماده مثل فرم گوگل با نمایش پاسخ‌ها
- یا همون کامنت زیر پست‌های اینستاگرام (که رایگانه و همین الان داری)

## نحوه کار سفارش‌گیری
سایت یک **کاتالوگ آنلاینه**، نه فروشگاه با پرداخت مستقیم. فلوی سفارش:

1. کاربر محصولات رو به سبد خرید اضافه می‌کنه (ذخیره با `localStorage`)
2. توی صفحه‌ی `checkout.html` اطلاعات گیرنده (نام، موبایل، آدرس) رو وارد می‌کنه
3. با زدن دکمه‌ی «ثبت سفارش در اینستاگرام»:
   - یک متن خلاصه از سفارش (محصولات، جمع مبلغ، اطلاعات گیرنده) ساخته می‌شه
   - این متن به‌صورت خودکار کپی می‌شه (`navigator.clipboard`)
   - یک باکس با همون متن (برای کپی دستی در صورت نیاز) و دکمه‌ی لینک به پیج اینستاگرام `bafika_2026` نمایش داده می‌شه
4. کاربر پیج اینستاگرام رو باز می‌کنه و متن رو توی دایرکت پیست می‌کنه

هیچ پرداخت آنلاینی انجام نمی‌شه؛ تسویه‌حساب و هزینه ارسال از طریق دایرکت هماهنگ می‌شه.

## اجرا
فقط `index.html` رو با مرورگر باز کن (ترجیحاً با Live Server توی VS Code)؛ نیازی به نصب چیزی نیست.
